## Threaded MCP User Interface

A simple, clean web interface to run all four server variants.

## Prerequisites

- Node.js (v14 or higher)
- Docker installed and running on your system
- npm

## Installation

1. Install dependencies:
```bash
npm install
```

## Usage

1. Start the server:
```bash
npm start run
```

2. Open your browser and navigate to:
```
http://localhost:5050
```

3. Enter your parameters in the input fields and click "Start"
