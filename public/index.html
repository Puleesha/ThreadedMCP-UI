🔥 Prometheus Guide

Target states

UP — scraping successfully.
DOWN — server unreachable; check if the variant is running.

Expected targets

You should see four targets after clicking Start — one per server variant.

Scrape interval

Metrics refresh every 15 s by default. Allow one interval after a run before querying.

Query console

Visit /graph and try rate(mcp_requests_total[1m]) to inspect throughput.

💡 A target stuck in DOWN usually means a port mismatch — confirm each variant's --metrics-port matches the Prometheus config.
